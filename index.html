How a trainer works

Stage 1

Learn

Small batches. Each item goes from multiple choice to typing it to typing it again later. Miss one and you type the right answer out.

Stage 2

Final test

Everything shuffled, no hints. You need a perfect score to move on. Misses go back to practice.

Stage 3

Apply

Use it for real: sentences to translate, word problems, or "explain why" questions.

Stage 4

Bonus

Flip it around, like English → Latin or definition → term.

New in v2: every item is learned both ways, ⚡ cram mode for the night before a test, long-term reviews spaced over days, and a 📅 test date. Every trainer also has 💡 memory tricks, ⚠️ warnings for look-alike items, 🔥 streaks, accuracy, and your toughest items. Progress saves automatically.

Install the skill in Claude

  1. Download study-skill-v2.zip (latest). The original is still available as study-skill-v1.zip.
  2. In Claude, open Customize → Skills (claude.ai/customize/skills).
  3. Click +, then Create skill, then Upload a skill, and choose the zip.
  4. Make sure the skill is toggled on. Skills also need Code execution and file creation turned on in Settings → Capabilities.

Already have v1? Turn it off so Claude uses v2. More detail: Use Skills in Claude (Anthropic Help Center).

Use it

Start a chat, attach your material, and say:

"Make a study trainer from this."

Or be more specific:

"Make a study trainer from this photo of my biology vocab."
"Here are my Spanish chapter 5 words. The apply stage should be sentences."
"Make a study trainer from these history notes, focused on dates and causes."

Claude sends back an .html file. Open it in any browser, on a computer or a phone, and start studying.
